# KALAY-AI — цель проекта (заморожено: 2026-09-19)

## Миссия
Семейство обучаемых агентов для стратегических игр с неполной информацией на базе
Player-Centric R-NaD + NeuRD. Алгоритмическое ядро — `SPEC.md` (v6.1, единственный
источник истины).

## Босс-лестница
- **Boss 1: Slumbot** (Heads-Up No-Limit Hold'em) — финальный экзамен Фазы 1.
- **Boss 2+ (будущее):** 6-max, 9-max, другие форматы и игры. Поэтому интерфейс
  `GameEnv` и формат траекторий N-player с первого дня; движок не знает покер.

## Фазы и ворота
| Фаза | Содержание | Ворота выхода |
|---|---|---|
| P0 | Ядро + лесенка игрушек: RPS → Kuhn → Leduc → Push-Fold → HULHE-toy → HUNL-toy | Каждая игра проходит свой пререгистрированный tier_b тест |
| P1 | Полный HUNL (симулятор, two-hot сенсор, translation действий) | NashConv-прокси на урезанных стеках, cross-play стабильность |
| P2 | Slumbot | Матч-протокол против бота, положительный винрейт на длинной дистанции |
| P3 | Мультиплеер (6-max+) | Исследовательская фаза: теория за пределами 2p zero-sum |

## Критерий арены мощного железа
Железо арендуется **только после** того, как локально (CPU / 1 GPU) пройдены ворота
Leduc и Preflop Push-Fold из tier_b. Не раньше: до этого узкое место — не вычисления.

## Принципы (не нарушаются)
1. **Тесты = истина.** Tier A (инварианты) заморожены навсегда. Tier B (сходимость)
   пререгистрированы до первого запуска и заякорены на внешнюю правду (аналитический
   Нэш, литературные бенчмарки), пороги не подгоняются под результат.
2. **SPEC.md — источник истины.** Изменение поведения = явная ревизия спеки с версией.
3. **Eval — первоклассный модуль.** Утверждение о сходимости = число из `kalay/eval`.
4. **Масштабируемость:** движок ест `(obs, legal_mask, reward)`; игры — адаптеры;
   канонизация карт — отдельная библиотека `kalay/cards`.
5. **Честная отчётность:** провал ворот = диагноз и фикс кода/конфига, но не порога.
