# KALAY-AI

Player-Centric R-NaD + NeuRD движок для игр с неполной информацией.
Цель и фазы — [GOAL.md](GOAL.md). Алгоритм — [SPEC.md](SPEC.md) (v6.1, заморожен).

## Быстрый старт

```bash
cd C:\projects\kalay-ai
python -m pytest tests/tier_a -q -n auto  # инварианты (~20 c, параллельно)
python -m pytest tests/tier_b -q -n 3     # сходимость: 6 тестов на 3 воркерах (~17 мин
                                         # вместо ~49 последовательных минут)
```

## Структура

```
kalay/
  core/      движок: батч+контракты, V-trace, NeuRD-лосс, R-NaD engine, коллектор
  games/     адаптеры игр (N-player интерфейс): rps, kuhn, (leduc, pushfold, ...)
  cards/     S4-канонизация карт (hand-locked, орбитальный коллапс пар)
  eval/      табличный best response (по инфосетам), NashConv, якорное усреднение
  testing.py хелперы тестов
tests/
  tier_a/    ЗАМОРОЖЕННЫЕ инварианты (SPEC 3-5): контракты, маски, NaN-безопасность,
             канонизация (орбита 24 перестановки), правила игр, механика движка
  tier_b/    ПРЕГИСТРИРОВАННАЯ сходимость (SPEC 8): RPS, Kuhn; пороги из внешней
             правды (аналитический Нэш), не из нашего вывода
```

## Принципы

1. Тесты = истина: tier A заморожен навсегда, пороги tier B не подгоняются.
2. SPEC.md — источник истины; гиперпараметры тюнятся, поведение — только через
   ревизию спеки.
3. Любое утверждение о сходимости — число из `kalay/eval`.
